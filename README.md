This repository contains my solutions to **HCLTech Python QA – Basic Level**, consisting of **5 Python Simple Loops programming problems** focused on basic iteration, number sequences, summation, reverse iteration, and conditional number selection.

Each solution is implemented in Python with an emphasis on **readability, correctness, simple logic, and clean coding practices**.

# Problem List

| No | Problem                                      | Expected Output               |
| -- | -------------------------------------------- | ----------------------------- |
| 01 | Print numbers from 1 to 5 one by one         | `1 2 3 4 5`                   |
| 02 | Print numbers from 5 to 1 one by one         | `5 4 3 2 1`                   |
| 03 | Find the sum of numbers from 1 to 5          | `15`                          |
| 04 | Find the sum of numbers from 5 to 1          | `15`                          |
| 05 | Print even & odd numbers from 1 to 10        | `1 2 4 6 8` , `1 3 5 7 9`     |

## The original problem statement specifies these five exercises and their expected outputs.

# Running the Programs

## Clone the Repository

```bash
git clone https://github.com/samuvelrajappa/HCLTech_Python_QA_Basic_Level.git
```

Move into the project directory.

```bash
cd HCLTech_Python_QA_Basic_Level
```

Navigate to the solutions folder.

```bash
cd Looping
```

Run any Python solution.

```bash
python Python_Simple_Loops_Problem1_Solution.py
```

or

```bash
python3 Python_Simple_Loops_Problem1_Solution.py
```

Repeat the same for any solution file from **Solution_01.py** to **Solution_05.py**.

If you'd like to use these solutions or contribute:

1. Open the repository.
2. Click the **Fork** button at the top-right corner of the GitHub page.
3. Clone your fork to your local machine.


